# 医疗知识库使用规范（演示资料）

> 本文仅用于演示系统的证据治理流程，不构成诊断、处方或临床指南。真实医疗回答必须核对当前有效的权威指南、监管机构药品标签和专业人员意见。

## 证据优先级

优先使用现行临床实践指南、政府或药品监管机构发布的说明书与安全通告，其次使用系统综述、随机对照试验和同行评议研究。网页摘要、论坛和模型记忆不能作为高风险结论的唯一依据。

## 版本与适用范围

每份资料应保存发布机构、标题、版本、发布日期、适用人群、地区、有效状态和原始链接。发现多个版本时，应优先识别现行版本；无法确定有效状态时必须提示用户核验。

## 证据不足与冲突

没有足够证据时应明确说明无法回答。来源冲突时应列出各自版本、适用人群和差异，不得合并成一个看似确定的结论。

## 人工审核

涉及诊断、处方药、停药换药、剂量、妊娠哺乳、儿童、老年人、肝肾功能异常或严重不良反应的结论，应由医生或药师审核。
