# 常见用药安全框架（演示资料）

> 本文提供信息组织框架，不提供具体药物的个体化用法用量。

## 核对药物身份

记录药物通用名、商品名、剂型、规格、给药途径、使用原因和实际使用方式。名称相似或复方制剂需要逐一核对成分。

## 核对患者因素

仅收集决策所需的年龄范围、过敏史、妊娠或哺乳情况、肝肾功能、相关疾病以及既往严重不良反应。避免收集身份证号、完整住址和无关病历标识。

## 核对合并用药

同时核对处方药、非处方药、中草药、保健品和近期停用的药物。相互作用结果需要说明机制、严重程度、证据来源、监测方式和升级处理条件。

## 输出边界

系统可以解释药品标签和指南，但不能替用户开具处方或擅自调整剂量。可能涉及停药、换药和剂量变化时，应联系医生或药师。
